# Tenant agent inventory and Access

Mode: Operate. Ordinary code-led extension of the incumbent Ant Design v6 dark admin system. `/docs/19-multi-tenant-iam-ux.md` owns behavior; this brief describes presentation only. No new visual world, concept seed, comp or raster asset is required.

## Direction contract — 2026-10-17

**THESIS:** A person can distinguish permission to talk to an agent from the agent's independent authority, inspect scope and make a deliberate exact access change without leaving the established admin shell.

**OWN-WORLD:** Preserve native Ant Design typography, semantic status colors, flat reading surfaces, compact collection rows, bounded drawers and the 8/12/16px shared spacing owners. Reuse AdminShell, collection toolbar/pagination, shared form feedback/confirmation and scoped command/query hooks.

**STORY:** A readable inventory leads to one agent's Access page. Who can chat precedes What can this agent do. Direct/inherited source labels and Core-computed permission results explain authority. Confirmation names the agent and organization. Technical IDs stay in disclosure. Empty, denied, stale and retry states preserve honest outcomes and selections.

**FIRST VIEWPORT:** The agent identity, organization context, back navigation and first chat-audience rows are readable immediately. Scope and role controls wrap at narrow widths. The second section follows naturally in document order; no decorative dashboard or parallel settings menu.

**FORM:** One reading column with native Flex rows and disclosures; a protected creation Drawer only for a real draft. Signature interaction is the explicit scope selection updating Core-computed authority while chat access remains separate. Native loading/focus/Drawer motion is sufficient; no authored decorative entrance motion. Keyboard order follows reading order and confirmation/Drawer close restores focus.
