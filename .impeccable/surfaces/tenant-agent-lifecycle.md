Primary target web/src/features/access/TenantAgentLifecycle.tsx. Related AccessApp, TenantAgentAccess and TenantAgents. Operate, code-led extension of the established Ant Design dark System/organization world. No comp, quality card, imagery, CSS, tokens or visual identity replacement.

## Direction contract — 2026-10-20

**THESIS:** Inspect one Agent's current lifecycle and deliberately archive, restore or permanently retire its exact owned identity.

**OWN-WORLD:** Reuse AdminShell, AgentConfigurationPanel, responsive Descriptions, native Alerts/Buttons and shared centered danger confirmation. Existing 8/12/16px stack/insets own spacing; no new layout rules.

**STORY:** Lifecycle is the single owner for archive/restore/decommission. Access keeps roles/audience. Coherent server facts name the Agent and organization and supply independent update/delete hints, reference blockers and exact revisions. Retired facts remain readable through the deliberate lifecycle projection while live inventory hides the owner.

**FIRST VIEWPORT:** Agent name/status, organization context and recoverable read control lead. Active state explains reversible archive. Archived state separates restore from irreversible retirement and names resource cleanup/history blockers. A retired state separates saved identity retirement from confirmed/pending/unconfirmed physical cleanup.

**FORM:** No editable draft or custom control. Signature interaction: exact named confirmation → one mutation → saved logical/cleanup facts; uncertain/stale reply disables commands until explicit readback, with a fresh confirmation for any new action. Native focus enters confirmation and returns to the action or readback. Narrow details stack and actions/long names wrap.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
