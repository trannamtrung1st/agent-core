# General Workbench build inputs and notices

[Operations](../../docs/17-observability-and-operations.md#trusted-local-opensandbox) owns launch/cleanup and Core environment overrides. The dedicated native runner is the supported reproducible local deployment; ordinary Synthetic startup stays Docker-free.

`Dockerfile.workbench` pins Python/Node base digests, Debian's 2025-10-01 snapshot, TypeScript 5.9.3 and hash-locked Python dependencies. It installs data/Office libraries, LibreOffice, git/curl/jq/archive/PDF/font utilities once. Commands run as UID/GID 1000 in `/working`. Runtime has no dependency downloads or provider credentials. Optional initialization belongs to an immutable Global profile and runs after Core hydration, once per generation.

Python requirements are generated from `requirements.in` and enforced with `pip --require-hashes`. Image content IDs are recorded by the runner; local IDs require explicit Core configuration. Input pinning is reproducible; image IDs can differ by architecture/build metadata and are not a bit-for-bit provenance claim. Keep the exact exported image ID associated with its installed inventory.

`inventory.py` exports SPDX 2.3 for installed Debian, Python, npm and Node components plus actual license-file hashes. The runner exports `workbench.spdx.json` and `workbench-licenses.tar.gz` beside `image.json` under gitignored local state. The 2026-10-14 macOS/arm64 export contains 498 package identities, 277 notice hashes and 547 retained notice files. Unknown/compound metadata remains NOASSERTION with its upstream declaration retained; this is inventory, not legal conclusion, vulnerability assessment or signed attestation. Debian/LibreOffice, Python, Node/npm and individual libraries retain their own notices; Node's release license is explicitly copied from the pinned image. OpenSandbox 1.1.1 is Apache-2.0; retain its upstream distribution notices. Agent Core source remains proprietary under the repository LICENSE.

The Workbench intentionally disables pytest's optional cache provider because it creates a protected `.gitignore`; pytest still executes real tests. Existing Core protections for `.env`, `.git*`, links, special files, quota/count/path collisions and exact canonical imports remain active. `/home` is independent. Docker writable-layer storage quota and stronger own-loopback isolation are deferred production hardening, disclosed in Admin and Operations.
