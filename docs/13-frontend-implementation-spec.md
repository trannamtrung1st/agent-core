An empty scoped catalog offers **Connect a provider** only to a current connection administrator; other users see owner guidance. An unavailable inherited default with selectable offerings explains **Choose a model for this chat** and optionally links an authorized administrator to Defaults. Explicit selection hides the guide. System **Stored tenant registrations** counts retained offering registrations, including disabled/retired ones; it never represents executions or provider health. Tenant preset views contain no system aggregate. Tables retain local horizontal scrolling on narrow viewports.

The connection credential picker shows the safe credential name plus **Last key replacement in Agent Core**, derived from audited replacement events. No recorded event and unavailable/off-page metadata have separate honest text. Ordinary metadata edits do not change this date. The form never receives or echoes the protected value.

Connection and model rows expose **References** independently from management actions. The bounded native Drawer switches Organization default, Definitions, Instances, Automations, Conversations and Runs, with twenty rows per page and readable-only totals. Changing categories clears the previous result while loading or on denied reads. The user must choose **Apply configuration change**; **Keep editing** retains the draft without a write. A failed or stale reference preview closes confirmation and requires current readback before another save. No disabled route is replaced automatically. The shared viewport-bounded Ant Design Modal composition keeps header/actions visible and scrolls the preview body; narrow controls retain forty-pixel hits. Collection action groups may wrap within the model-management Actions column.

Organization **AI models** uses the existing `AccessApp`/`AdminShell` at `/t/{tenantId}/integrations/ai-models/connections`, `/models` and `/defaults` (the latter two replace only the final path segment). Platform **Model catalog** is `/system/model-presets`. These are standard Ant Design v6 collections and bounded forms. They introduce no additional UI kit, theme, CSS layout system or execution owner.

Connections explicitly select a native provider or a host-permitted compatible endpoint, an owned protected inference key (or an explicit custom-only no-credential mode), enablement and a name. Native endpoints are code-owned. The existing Credential editor can create a model-inference API key within connection setup; its protected input clears on submission and never enters model state. Model inference keys are excluded from Agent tool bindings. Metadata tests and discovery have explicit human actions and show separate Synthetic/listing evidence; neither is an inference or capability certification badge.

Models can deliberately adopt compatible enabled starter presets or register an explicit capability/transport declaration. Discovery adds disabled unknown registrations and preserves operator configuration. The table separates enablement/retirement, observation, declared capability provenance and server-reported admission eligibility. Connection names distinguish offerings of the same external model. Current default references prevent disabling/retiring that model; the API remains authoritative for all in-use guards. Shared system presets contain no tenant credentials and changing their metadata does not rewrite copied tenant declarations.

Defaults require a deliberate available offering and a supported reasoning effort, or deliberate removal of the default. The current unavailable selection remains visible without substitution. Read-only users can inspect only their readable projections; action controls use server-reported per-resource authority, with no separate model-use permission. Every mutation carries exact security/resource revisions. A refused or uncertain command disables another save until explicit readback; drafts remain intact. Connection readback shows current authentication mode/key reference alongside the retained draft key; default readback includes the connection qualifier. These are nonsecret references. Native draft guards, wrapping Drawer footers, local table scrolling and focus restoration retain their existing owners.

Focused Synthetic API/browser qualification covers nested protected-key setup, connection test, starter adoption, explicit default/effort and reload, stale edit/readback/save, shared preset isolation and a real read-only member. Rendered model views and editor/default guards were checked at 1440, 768, 390 and 320 CSS px. Canonical identity/storage and Synthetic bindings now have their own focused evidence; Definition/Instance and unattended/gated-Automation browser paths now have focused evidence; the later selector fix verdict and fresh final-completion full SHIP review are complete at their recorded scopes. ## Voice preflight

User activation may expire before a queued `pendingMode=voice` wait finishes. When a session already exists, the Voice click prepares audio locally first. When Voice is the first action, create/attach first so preflight can use `session.ready` transports and skip getUserMedia for Browser/Browser; then ask the server to change mode, and only then send PCM.

```text
User clicks Voice
    ↓
if no session exists: create and attach a text session, then wait for session.ready transports
    ↓
local audio preflight using advertised transports
    ├── if stt.transport is clientTranscript: do not call getUserMedia for STT PCM
    ├── if tts.transport is serverAudio (including mixed clientTranscript+serverAudio): create/resume AudioContext and initialize playback worklets
    ├── if tts.transport is clientSpeech and stt.transport is serverAudio: request microphone and input worklets; do not load PCM playback worklets
    ├── if both transports are client-side: skip capture worklets; start the client recognizer/synthesizer adapters
    ├── if stt.transport is serverAudio: request microphone permission and input worklets
    └── DO NOT send PCM yet
    ↓
send session.mode.set(voice)
    ↓
if pending:
    show Starting voice…
    retain prepared audio resources
    offer Cancel (session.mode.set(text))
    ↓
server Mode becomes voice (streamId issued)
    ↓
if serverAudio STT: start sending microphone PCM
if clientTranscript: start ClientSpeechRecognizer and emit client.speech.evidence (partials ephemeral; one application final per utterance). Native `SpeechRecognition` `isFinal` chunks are application-stable pieces, not utterance boundaries; `onspeechstart` (or first result) opens the turn, `onspeechend` is pending until a trailing native final or a 300 ms grace heuristic closes it, and native `onend` flushes only when `speechend` is already pending. The BrowserSpeechRecognizer also closes an application utterance after about 1.8 s without a new transcript update (pause in recognized language) by emitting `ended` with `utteranceOpen` cleared so a later Chrome result can start a new utterance id, and discards noise-only turns after about 4 s with no recognized text through nonfatal `failed` evidence; `speechend` remains the fast path when Chrome provides it. Render `transcript.partial` as an ephemeral live user bubble; `transcript.final` (with entryId and entrySequence) becomes the durable user entry after SQLite save. `transcript.discarded` clears the live bubble without adding history. While Browser TTS is playing, locally suspend Browser STT from `agent.response.started` through response terminal and client playback completion without changing server mute or leaving voice mode, so speaker audio is not re-transcribed; resume with a fresh transcript epoch afterward. Mid-utterance native `onend` without `speechend` keeps the Agent Core utterance open and relies on accumulator `unexpectedRestart()` to freeze the spoken prefix and stitch overlap-aware continuation text across the native restart. Native `onend` is also recognition-session termination: restart immediately while no application utterance is open; during an open utterance use bounded restart/backoff plus a cap on consecutive service ends without speech progress (`SpeechRecognitionRestartLimit`); do not treat session `onend` alone as `ended`. Permission/device/service errors mark recognition inactive and surface the structured speech error.
    ↓
if serverAudio TTS: play AudioWorklet PCM
if clientSpeech: queue speech.output.segment (including language and speakingRate), await each utterance `onend` before the next segment, ACK playback.* with consumedSamples=0, and call speechSynthesis.cancel only on explicit Stop/Steer/barge-in/playback.stop/disconnect
```

If preflight fails (permission denied, missing AudioWorklet, suspended context that cannot resume), do not send `session.mode.set`. If the mode request fails, is cancelled, the connection drops, or `PendingVoiceTimeoutMs` elapses, release prepared resources, clear the user-initiated voice latch, and return to the text composer. After reconnect, `pendingMode` is null; the user must press Voice again so a new gesture can preflight. A cancelled in-flight Voice click must not look user-initiated on the next attach, or the client skips the passive durable-voice → text downgrade.

Do not claim Listening until Mode is voice and either capture is sending (`serverAudio`) or the client recognizer is started (`clientTranscript`). If the device rate is 44.1/48 kHz, resample continuously with preserved filter state; never assume 24 kHz device support.

The output worklet validates its active response epoch and stops at the next render quantum on flush, with a short fade where practical. It reports consumed samples independently of UI rendering. The connection service emits playback acknowledgements every 100 ms. Text and voice both emit `response.received` every 100 ms and at final render for the rendered **display** prefix and delivered blocks; de-duplicate those receipts on the pair (display offset, delivered block-ID set), not the text offset alone. Those display receipts must not be copied onto heard. These receipts are advisory delivery evidence, validated on the server. Queue underflow outputs silence without advancing consumed samples. Queue overflow triggers a recoverable AudioBackpressure error and stops that response.

Local VAD ducking is an optional, independently disableable UX optimization; restore gain after controller Continue/Ignore or timeout. Only authoritative supersession/stop/end/disconnect tombstones a response. Never mute microphone automatically to solve speaker echo.
