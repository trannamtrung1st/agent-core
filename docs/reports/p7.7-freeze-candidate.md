## Ownership and security

One server-generated `DiagnosticId` identifies an unexpected failure. `IDiagnosticIdSource` uses `Guid.NewGuid()` and does not dequeue `IIdGenerator`. `FailureReference` stores that id, an optional correlation id, and bounded category/code on a failed assistant entry. Terminal work stores `FailureDiagnosticId`. Retry, cancellation, validation, not-found, conflict, protocol rejection, and host shutdown do not.

The id is a first-class wire and ProblemDetails field. It is not an extension and not a metric label. Clients cannot set `diagnosticId`, `correlationId`, or `causationId`. Copy text and history omit conversation text, stacks, paths, payloads, and credentials. `Observability:OtlpEnabled` still does not attach an exporter. There is no diagnostic table and no second hub. `protocolVersion` stays 1. MessagePack remains the default on `/hubs/session`.

SQLite adds nullable `FailureReferenceJson` (`20260929121048_P7FailureReference`) and nullable `FailureDiagnosticId` (`20260929125852_P7WorkFailureDiagnosticId`).

## Scheduling

Domain ownership of registration, schedule semantics, occurrence admission, work, approval, and execution is unchanged. Infrastructure still wakes and dispatches with `BackgroundService`, SQLite, one process, and a 1-second cadence. A missed recurrence still coalesces to the latest due occurrence. `CoalesceLatest`, `SkipMissed`, `CatchUp`, Hangfire, and Quartz are recorded as deferred and are not implemented.

## Manual MessagePack, JSON, and failure trace

JSON diagnostic mode is `JavaScript_json_diagnostic_roundtrip`. The JavaScript client uses SignalR JSON on the same hub, checks one audio frame, the failure id in history, and client correlation rejection. DevTools was not used again for this report; that client scenario is the JSON frame evidence.

The browser does not capture the server log line. Playwright owns the visible copy and reload. No public test-only failure endpoint was added.

## Redaction

The session error sanitizer still drops stack, trace, path, body, payload, raw, and credential extensions. `diagnosticId` is parsed as its own field before that sanitizer. Expected 4xx and host shutdown responses omit it. Activity tags do not carry the diagnostic id. The Playwright copy assertion does not contain the user text `synthetic-fail-turn`.
