# Instance Skills UI polish

The Skills tab separates descriptive metadata into desktop columns and retains compact metadata with local table scrolling on narrow screens. Search includes requirements and copy provenance. Inspect expands inside its owning row; Close inspection restores focus. New/Edit use an Ant Design right-side drawer with a scrolling form, counters, activation help, and persistent Save/Cancel actions. Below 768px the drawer fills the viewport. Failed saves retain values and show recovery inside the drawer. Dismissal waits for writes; focus restoration waits for reload and the closing transition. Switching tabs hides the drawer while retaining its draft. Definition/local ownership, explicit Customize confirmation and revision fencing remain unchanged.

Runtime verification used Playwright MCP against a Synthetic in-memory host at ports 5118/5198. Create, save, reload, inline inspect/close, keyboard Escape, and a deliberately injected 503 followed by successful Save were exercised. The draft survived the failure. Desktop 1440px and mobile 390px were inspected together; the initial mobile drawer sizing defect was corrected to full-width. The final mobile drawer measured 390×844 with no page overflow. The only related console error was the deliberately injected 503; subsequent writes and reads returned 200.

Inspection now labels the content Procedure instead of repeating the Skill name. Opening focuses the close button rather than the duplicated name; mouse close and keyboard Enter restore focus to Inspect. The mobile reading width uses the enclosing table and padding token. Playwright MCP checked 1440px and 390px, including long wrapped content, closing/reopening and keyboard dismissal; no page overflow, console errors or warnings. Seven Skills unit tests, all four Skills Playwright journeys (28.3 seconds), production build and TypeScript checks passed. The existing bundle-size warning remains.
