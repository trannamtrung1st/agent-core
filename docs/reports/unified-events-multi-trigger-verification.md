## Implemented behavior

Global Events combines immutable safe Built-in definitions with managed Webhooks through typed source references. Built-in schema/examples are illustrative and contain no private occurrences or credentials; subscriber navigation loads an owned Instance. Independent catalog reads retain successful branches after partial failure and expose retry.

An Automation owns exactly one Schedule child or 1–32 Event children using OR matching. Stable child IDs, independent configuration revisions, per-child enablement/filter/dispatch, atomic parent/child CAS and source-identity replacement rules are canonical through Domain, stores, Admin and chat tools. Disabled authoring is structurally validated independently of execution permission. Enablement and admission still enforce current authority, resource/model/destination state and causal limits. Manual Run now belongs to the parent and fabricates no Event child.

Core/Webhook deliveries, retries, dedupe, buckets and coverage retain exact child identity. Frozen filter semantics survive edits/restart; current disable/removal/revoke prevents new admission. Webhook-supplied root/depth cannot establish trusted causation. Safe Run provenance shows the admitted child/source/revision and definition link from immutable owned evidence. Migration preserves parent identity/provenance/revisions, seeded child identity, receipts/decisions/retries, buckets/coverage and historical instructions/source links. It supports backup restoration rather than a lossy downgrade.

The existing Ant Design drawer preserves separate unsaved Schedule/Events branches and per-child samples, supports a grouped searchable picker, confirms removal and returns nested Webhook creation to the initiating row. Custom and preset drafts start disabled. Save, Save & enable and Save as disabled explain their distinct eligibility. The bounded responsive review retained shared layout, footer and focus behavior.
