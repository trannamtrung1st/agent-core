## Result and owners

- **One profile contract:** `SandboxProfile` retains immutable CAS revisions and adds optional registry credential identity. `OciImageReference` parses explicit canonical registry/repository sha256 digests and gated local IDs, matching complete host/path segments. Tags, malformed hosts/ports, spoofed prefixes, controls, Unicode and credential-bearing URLs fail closed.
- **Protected supply authority:** `ContainerRegistryProfile`, CredentialService and both credential stores reuse encrypted System Credentials. Exact host/repository scope, expiry, logical/secret revisions, replacement, disable/delete and store-level binding denial fence pulls. Safe owner DTOs expose scope/IDs only. A narrow Application authority port carries no protected value or SDK DTO.
- **Verification/admission:** SandboxImageAuthority, OpenSandboxService and Verification supply transient official SDK ImageAuth for checks and real generations. A bounded anonymous/authenticated remote manifest probe handles Basic or bearer challenge authorization, with no redirects/cookies, 15-second budget, 64-KiB token response and explicit HTTPS token-service origins; loopback insecure exceptions are host-only. This prevents cached daemon images from masking bad rotated credentials or missing private authentication when declared public. The deterministic probe race test rotates a credential before SDK creation and observes **zero create requests**.
- **Readiness:** authenticated server readiness is independent of inventory. Enabled intent and an old observation do not authorize execution. Exact current-contract verification and credential epochs plus current server readiness gate new Run pins and selection. Verified configuration remains inspectable as ServerUnavailable when the server is disabled/unreachable. Full profile verification persists an observation without advancing configuration revisions; image-only checks remain ephemeral and skip setup. Saved source disable remains possible after revocation.
- **Legacy retirement:** no executable sandbox.run descriptor/handler, LegacySandboxCommands, implicit default lookup or WorkbenchImage seed remains. Historical publications/receipts are retained; old tools fail closed and require explicit republishing/adoption. Modern exec, processes, reset, receipt-before-effect, canonical scratch, cleanup and existing generation pins remain owned by their original services.
- **Deployment:** normal Compose/local preparation builds no workload, emits no Workbench default and does not force local IDs. Optional `--build-workbench` explicitly retains the maintainer fixture/SPDX/notices; opt-in tests can instead pass an exact `--image`. The optional app overlay has no Workbench dependency. The optional CI command was updated for explicit fixture building, without dispatching CI.
- **UI:** shared Admin toolbar/table, guarded Form, advanced disclosure, historical read-only revisions, safe registry selector and existing Credentials Modal replace single-Select onboarding. Definition/Instance pickers expose status and retain unavailable stored IDs; draft repair is explicit. Shared profile details and the Session drawer show safe source/image/revision pins. Ant Design v6, existing shell, theme tokens, confirmation and Office/file preview remain the presentation owners.

Forward migration `20261014163203_OciSandboxRegistryAuthority` adds only nullable `Credentials.ContainerRegistryJson`. Profile/lease/verification metadata use existing revision JSON. Old observations deserialize with contract version 0 and require reverification. The populated pre-upgrade test preserves exact profile ID/revision, Definition policy JSON, Instance selection, live lease/Instance revision pin, uncertain execution receipt and historical observation. No user database, Workspace, Artifact or journal reset occurred.

## Boundaries and completion

This is the complete local OCI contract cutover with observed focused security/runtime evidence; it does not claim every production/device/architecture gate. Linux-host/amd64 execution, customer public/private registries and cross-origin bearer token services, unsupported CPU architecture, native browser zoom, manual screen-reader/audible/device checks and exhaustive combinations of every UI edge state were not executed here. The actual registry tests used controlled local authenticated and anonymous OCI fixtures. Existing own-execd loopback access, one server per daemon and lack of hard writable-layer disk quota remain accepted trusted-local limitations. Hosted CI and the full unrelated CI suite were not run.

Canonical source, safe DTOs, schema, deployment and frontend are wired together. No database reset, compatibility alias, implicit profile, local-image fallback, user builder, multi-container workload topology or agent secret grant ships. Test resources are stopped after verification; owned metadata/fixtures/evidence remain recoverable, and original images/volumes and unrelated resources are preserved. Any failed gate remains explicit in this report rather than being counted as historical milestone acceptance.
