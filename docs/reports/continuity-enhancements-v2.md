## Delivered behavior

- A read-only Application Continuity projection finds retained Memory, derived Experience and historical Sessions without replacing their stores or admission rules. Deterministic relevance/recency selection carries kind, source, scope, checkpoint/date and Definition provenance.
- Core-scoped `continuity.search` and `continuity.get` recheck current eligibility, visibility and retrieval policy. Automatic prompt recall uses bounded historical hints; explicit get inspects a bounded range. Conservative received/heard projection omits streaming, hidden and undisplayed assistant output. Trusted System warnings and ordinary historical User data keep current policy/task and approval authoritative.
- Host maintenance supplements stable lifecycle/work boundaries every five minutes. Durable active-session checkpoints reuse Experience's deterministic identity, repairable admission outbox and independent recoverable Retrospection WorkItems. Empty/unchanged/tombstoned checkpoints create no duplicate.
- Agent Instance Admin authors and manages known Scheduled Work without an LLM. Chat and Admin use the same registrations, preserve author provenance and revisions, and admit Run now through normal pinned occurrence → durable WorkItem execution. Disable, cancel and future edits retain normal current-policy/approval/recovery semantics.
- Thought consumes the same retrieval while retaining ThoughtActivation origin, bounded execution/approval and quiet successful NoAction. Background Work remains an execution surface.

## Limits and deferred scope

Recall is lexical and bounded to the latest 100 historical Sessions/Experience candidates. Automatic Session candidates rank title/persisted summary first and read at most five recent entry ranges; explicit search uses at most the last 100 entries per Session plus summary. Visible entries are capped at 700 characters. Automatic Continuity adds Experience/history only; structured Memory is supplied once through the existing learned-memory path. Detail truncation is signalled by hasMore; this is not exhaustive archive replay. Experience enablement and existing memory-retrieval policies control their respective sources.

Optional phase 6 remains deferred: shared synthesis classifier, semantic/vector retrieval, richer conflict/supersession ranking, generic owner Continuity search UI and richer summarization. No new migration, external service, provider, approval authority or multi-agent feature is introduced. Hosted CI/Compose and live-provider/physical audio verification are not claimed for this local follow-on; historical frozen evidence remains unchanged. Impeccable noted that DESIGN.md is newer than its generated design-system sidecar; sidecar refresh is separate from product implementation.
