Converted Schedule/manual Automation tasks can create exact detached children, wait for their real terminal successor, inspect/take/acknowledge owned completion evidence and deliver separately authorized reports to the actual parent Session. ## Ownership and persistence

`TenantTaskExecutionContract` provides shape/discovery, with exact saved causal ancestry enforced by `TenantExecutionLineage` and current authority repeated by the incumbent owners. Immediate-child task intent names its exact actual parent Run. Approval successors retain the same immutable task. Child Sessions of background parents use the actual System executor as creator while preserving their original requester and root. Current root/source policy fences provider context, report admission and final output. Report Runs cannot create more children.

Creation keeps independent `sessions.create` and `agent-runs.create` requirements. A one-time grant substitutes only for its exact primary permission; the second permission, raw reads and current capability remain mandatory. Completion read Review does not grant raw source access. A take token remains exact to the parent Run/generation; acknowledgment becomes Handled only in the successful current-source outcome transaction. Report-source read and report-Run creation remain separate exact operations and never mutate the finished child.

Migration `20261020200000_TenantIndependentChildControls` freezes the existing approval-table rebuild and all 43 guards. It extends four consent shapes for a null scheduled requester and replaces the account-only pair with two generic no-human task-lineage guards. The bounded recursive proof verifies the actual owned root/child/approval chain, immutable accepted Schedule occurrence, frozen instructions/revision, exact source Run and Session. Manual requester relabeling, root substitution and malformed ancestry refuse. No new state owner, table, permission family, worker or scheduler is added. Earlier migrations are unchanged.
