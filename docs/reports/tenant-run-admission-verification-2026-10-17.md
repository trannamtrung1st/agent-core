The requester is independent of Session creator attribution. A tenant Run owner has no global profile; mixed tenant/profile ownership and context disagreement are rejected. Only immutable references are retained, with no Account cookie, authentication-session reference or permission snapshot in execution context. Independent messages start their own root. Existing retries preserve identity. Autonomous-origin vocabulary does not admit fictitious human requesters; its actual tenant ingress remains pending.

Both stores atomically commit the accepted text entry, ordered source ownership, Activation, queued Run, Session/security revisions and safe audit. Commit rechecks the original human/session, security CAS and current actual Instance generation/executor. The client message ID is correlation only. Fresh-witness same-message replay returns the originally saved graph without another entry, revision or success audit; changed text conflicts. Queued work is bounded at 100 nonterminal Runs per Session. Attached/ending Sessions and pending input are fenced pending mailbox integration.

Run metadata independently requires exact Run read and owning Session read and returns only safe execution references/status/revisions/times. Queued cancellation requires Run cancel/read, Session read and exact Instance chat, current human/security/Run witnesses and a quiescent Session. It saves the real Domain cancellation; attached/ending Sessions or nonqueued Runs cannot be changed around a live mailbox. An authorized Session delete then retires direct Session and Run grants, redacts retained input and makes Run reads unavailable. Run/Activation lineage remains retained.

`TenantRunExecutionIdentity` extends existing Activations/AgentRuns with indexed relational tenant/executor/requester identity and exclusive profile/tenant ownership checks. Composite foreign keys bind actual owning Session/Instance/executor and same-tenant requester User; existing root/parent constraints remain. Mappers check serialized execution context against relational identity. Legacy Run read/dispatch/completion-repair paths exclude tenant rows, generic legacy admission rejects tenant owners, and global Session recovery leaves their state intact. No substitute global profile or compatibility execution route is introduced. Obsolete global authority/schema removal remains part of the final cutover.
