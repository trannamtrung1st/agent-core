# Canonical historical Session continuity verification — 2026-10-22

## Implemented scope

Owned `continuity.search` combines actual-User learned Memory with currently readable historical Sessions of the same Agent/executor. The current Session is excluded. Exact `continuity.get` supports learned Memory and bounded Session entry windows. History remains independently eligible when Memory is disabled or unreadable. No global Profile, arbitrary User selector or legacy Experience source is adopted.

The existing approval/Run/receipt owners now support typed `PreparedContinuityRead` and `inspect_continuity`. Required Review withholds source bytes until exact consent is consumed. A completed receipt can authorize only identical windows or exact learned facts in the same causal task, with current raw source reads and reviewer/independence checks. There is no exceptional raw-read grant. Source changes/deletion/revocation invalidate saved evidence; compaction cannot remove its witnesses. Provider, output, report and owning checkpoint/outcome paths retain those checks.

SQLite migration `20261021201045_TenantContinuityRead` explicitly rebuilds the existing approval CHECK while preserving its 26 incumbent guards and indexes, adds actual-root/source/immutable guards and refuses a populated downgrade. No new history, Memory or identity owner is introduced. Human preview and confirmation reuse the shared Chat/Approvals exact-read inspector.
