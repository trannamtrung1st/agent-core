No table, migration, audit writer or execution engine is added.

New System audit independently requires current System governance authority. Null tenant is a closed global-fact allowlist, never all tenants. Only allowed execution-free bootstrap/password/status/privacy facts with exact reason codes contribute rows/count. Targets are canonical UUIDs, host or unavailable; tenant/execution context and free-form private targets are excluded. Tenant Owner authority gives no System access.

The shared native AntD collection preserves desktop expanded details and the mobile Drawer. Explicit draft/Apply/Clear/Refresh, exact principal/local-time validation and server pagination retire prior details. Denial, scope change and malformed successful page/primitive rows retire visible data. System has its own route, explanation and navigation identity. Existing bounded-form/mobile sizing and 8/12/16 spacing retain their owners; only one shared wrapping-filter CSS rule is added.
