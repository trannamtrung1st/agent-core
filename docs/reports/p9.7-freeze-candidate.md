**Status:** implementation complete; final local/hosted closure gates in progress. The freeze candidate SHA and green hosted Synthetic run will be recorded after those gates finish. P9.6 remains closed on `d033bc6198f856e9dd007df7b6235c413eafa2c0`; P10 and P11 were not opened.

## Shipped lifecycle

An owner enables instance-owned Assisted or Managed policy and independent scopes. Preparation forks the active immutable Definition through the existing Authoring lifecycle. A bounded model execution can inspect, read exact permitted sources, author candidate knowledge/resources, Skills and operating instructions, and request eligible tool changes. Assisted edits and every tool change await an exact owner decision. Model calls cannot change policy, publish, adopt, access raw configuration, or execute production actions for verification.

Core validates revision/authority/resources, actual knowledge readback and existing Skill activation/procedure injection. A fictional Skill sample runs with no tools and stays a partial model assessment. Owner review exposes diff, provenance, procedure, current/stale evidence and limitations. Explicit Publish & adopt reuses the existing publisher and CAS instance adoption. Freeze revokes Authoring, retains publication evidence, and leaves normal Chat available. Further improvement deliberately re-enables policy and forks again.

## Practical limits and handoff

Production refunds/messages and subjective model quality remain external evidence, visibly represented as such. Live nopCommerce/hosted-provider demonstration is optional and was not invoked for this phase. A consumed approval after uncertain execution is not replayed; cancel/start another candidate. A failed adoption may leave an unused immutable publication while retaining the current instance version. Standard provider cancellation contracts apply. P9.7 adds no permanent self-improvement loop. After all closure gates pass, focus on investor-demo stabilization and presentation.
