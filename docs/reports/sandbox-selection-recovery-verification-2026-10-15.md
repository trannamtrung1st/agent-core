## Limits and deployment

This completes a trusted-local extension, not public/multi-tenant production isolation or renewed milestone acceptance. Sampling is not a hard disk quota: fast bursts, unlinked open files and OCI writable-layer consumption remain limitations. Native hardware power-loss behavior, physical screen-reader/touch/zoom behavior, a native AMD64 host and macOS x64 are not established by emulated/container tests. Credential rotation/scope changes have deterministic current-epoch coverage; no new customer registry/account or live model acceptance is claimed. Historical process identity beyond the retained safe quiescence rejection is unavailable.

Deploy matching binaries/UI and updated launcher settings with an intentional restart of the known host. The user's existing application was not restarted by this task. Never replay historical commands or setup to “test recovery.” Existing immutable configuration/publications, canonical `/working`, durable `/home`, Artifacts and original receipts remain preserved.
