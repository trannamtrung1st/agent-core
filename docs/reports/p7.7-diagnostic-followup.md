## What changed

`75a39b7` is the diagnostic behavior change:

- A terminal session-end persistence failure emits `Persistent save failed.` The raw exception stays in the server diagnostic log under the existing `DiagnosticId`.
- Expired-claim recovery returns the WorkItems it terminalized. `DurableReminderExecutor` logs those items with the diagnostic id already stored on them.
- Conversation failure logs include the pinned `AgentInstanceId` and `ProviderAlias` when they are known.
- Docker and the docs record optional `VITE_AGENTCORE_REALTIME_PROTOCOL=json` on the same hub. MessagePack stays canonical.

Hosted workflow `36594702224` ran before this commit. The run for `75a39b7` was cancelled when newer commits superseded it. There is no hosted-green SHA for these corrections yet. This follow-up is not a new freeze.
