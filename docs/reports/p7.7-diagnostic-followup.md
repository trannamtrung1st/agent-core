## Diagnostic and logging (`75a39b7` and related)

- Terminal session-end persistence failure emits `Persistent save failed.` The raw exception stays in the server diagnostic log under the existing `DiagnosticId`.
- Expired-claim recovery returns the WorkItems it terminalized. `DurableReminderExecutor` logs those items with the diagnostic id already stored on them.
- Conversation failure logs include the pinned `AgentInstanceId` and `ProviderAlias` when they are known.
- Docker and the docs record optional `VITE_AGENTCORE_REALTIME_PROTOCOL=json` on the same hub. MessagePack stays canonical.

## Learned memory admission (after `40a1d92`)

Agent-proposed, Core-admitted memory replaces phrase matching as the write authority. Proposals stage with semantic output and admit once when the response completes successfully. Reliable channels are native structured output or the adapter response function; `[[memory:...]]` remains best effort. Cross-session update and delete semantics follow promotion policy.

## Memory receipts, diagnostics, and scheduler (`0889091`–**`1cadf46`**)

Controller-owned **`memoryReceipts`** on the assistant envelope are separate from display and speech text. Inferred outcomes stay silent; user-explicit success shows a quiet Remembered/Forgotten indicator; user-explicit failure stays visible.

| SHA | Summary |
| --- | --- |
| **`0889091`** | Receipt projection to UI/history; bounded `InvalidResponse` `FailureReason` / `ProviderResponseChannel` on the same `DiagnosticId` without raw provider payloads; idle trigger scan summaries at Debug. |
| **`1b62afe`** | Receipt **`scopes[]`** from admission (layers covered), legacy persisted `"scope"` read compat. |
| **`6c40426`** | **`scopes`** documented as successfully established or confirmed layers; partial promotion keeps **`outcome`** coherent with **`scopes`** (not `*SessionOnly` when a cross-session layer succeeded). |
| **`1cadf46`** | Symmetric partial-promotion regression (identity succeeds, user blocked). |

Receipt contract (stable for P8 metadata):

```text
outcome = whether admission counts as a successful store at the session layer
          (not downgraded to *SessionOnly when a cross-session layer also landed)

scopes  = memory layers successfully established or confirmed by this admission
          (session, identityUser, user — no ids or raw content)
```
