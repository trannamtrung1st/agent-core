## Architecture

Authoring, Runtime, and Operations are responsibilities inside the modular monolith, not new projects. The map is in [System Architecture](../03-system-architecture.md).

Effective configuration is shared resolution primitives plus use-case-specific composition. `EffectiveConfigurationComposer` is not a universal runtime object: `ComposeAdmin` builds the Admin projection, and `MemoryPolicyOf` owns `definition.MemoryPolicy ?? MemoryPolicy.Disabled`. Session `Bind`, `DurableWorkContextFactory`, and draft evaluation do not call `ComposeAdmin`. The closure audit found no contradictory model, tool, resource, memory, or trigger default. Trusted profile is not an Admin field.

Refactors that landed:

- Shared Admin projection and memory-policy default (`f1ef9c2`).
- Bounded `OperationalDiagnostics` for the silent lifecycle, approval, quota, and Admin paths (`7f0afa6`).
- Admin draft-status, publications, and instance-identity spacing moved into `web/src/app.css` (`b0c2e09`).

Deliberately deferred:

- Splits of `SessionHost`, `AdminEndpoints`, `PromptContextBuilder`, `SessionToolExecutor`, `TriggerScheduleCommands`, and Session Runtime partials. Attach still applies a resumed snapshot when no conversation execution is open, and refreshes the projection only after open executions drain.
- History-free `AgentInstanceService` managed methods. Tests still call them.
- Merging managed and compatibility instance services, merging attachment, artifact, definition-resource, and workspace stores, and adding a project per responsibility box.

No behavior defect was found in the effective-configuration inventory, so there is no policy-fix commit.

## Infrastructure

```text
READY
  Model calls already go through ILanguageModel.
  ScriptedLanguageModel and OpenAICompatibleLanguageModel are separate adapters.
  DefinitionDraftSyntheticOfflineLanguageModel is the offline draft evaluator.
  CatalogBoundLanguageModel and SemanticResponseLanguageModel wrap an inner model.

LIKELY
  Tool execution has one SessionToolExecutor and several handlers behind it.
  Trigger admission has ports and one production scheduler path.
  A second tool host or trigger source would extend those boundaries.
  It does not exist yet.

DEFER
  ISandboxProvider. DockerSandboxExecutor remains the only sandbox.
  A generic plugin or MCP bus.
  A distributed scheduler or queue.
  PostgreSQL or another database.
  One universal provider interface for models, tools, triggers, and sandboxes.
```

P8 should start from one concrete provider need, not from a new universal interface.
