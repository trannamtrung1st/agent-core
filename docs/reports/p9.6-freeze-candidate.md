## Decisions taken

Model intent is pinned before live-versus-durable routing. Precedence is the trigger override, then the Agent Instance unattended default, then the conversation default. The pin is immutable after admission. Browser Capability v1 adds history navigation, richer actions, page lifecycle, bounded waits, and an explicit viewport capture. `browser.capture` is offered only to a vision-capable pin. `POST /api/v1/hooks/{webhookKey}/order-placed` checks one SHA-256 bearer, admits one allowlisted occurrence, and returns before the agent or browser runs. A trusted application event uses the same unattended browser lease and 32-step/240-second budget as scheduled work. A succeeded side effect whose tool result was not checkpointed is not replayed. `secretary` v2 is additive. `secretary` v1 and `general-assistant` v1–v12 were not edited. An unconnected application event may still offer `demo.sensitive_action` when the definition allows it. Other allowlisted tools and browser tools stay denied until the occurrence is connected. A legacy EnsureCreated database stamps the P9.6 migrations when those columns and the `WorkCaptures` table are already present.
