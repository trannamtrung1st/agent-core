## Decisions taken

Model intent is pinned before live-versus-durable routing. Browser Capability v1 stays bounded and provider-neutral. Webhook credentials belong to an `ExternalEventSource`; agents subscribe with `eventSourceId` and `eventType: order.placed`. `POST /api/v1/hooks/{sourceKey}` admits one allowlisted External Event, snapshots matching Trigger Registrations into `ExternalEventDelivery`, and returns before agent work. Pending deliveries finish on later scheduler passes and on duplicate delivery; subscribers who join after admission are not added. Occurrence dedupe is `order.placed:{sourceId}:{sourceEventId}`. Unconnected scheduled reminders stay tool-free (`Request.Tools == null`). Connected application events and occurrences with tools require explicit `work.complete`. The nopCommerce plugin retries 0.5s / 1s / 2s and never fails checkout on delivery errors.
