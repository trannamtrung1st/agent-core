## Limits and operations

Automatic recognition is deliberately limited to installed SDK roots `/usr/share/dotnet`, `/usr/lib/dotnet` and `/usr/lib64/dotnet`, with optional fixed-path image `readlink`/`tr` utilities. Images need neither utility when no build server remains. Custom installations or unsupported helpers can use an explicitly authorized `dotnet build-server shutdown` in their own command; otherwise rejection remains safe. This does not make arbitrary background writers safe or provide hard disk quotas. Console run is verified; long-running application servers retain existing tracked-background/deadline semantics.

The local Docker server and stock Linux ARM64 SDK provide actual workload evidence; this follow-up does not add native AMD64 hardware, customer-image, live-model or device acceptance.
