## Contract and implementation

Normal trusted-local owner Chat teaches durable role knowledge and reusable Skills through the existing model/tool/approval loop. `HarnessAuthority` is contextual instance policy authority, separate from Definition allowlists. Attached UserTurn, enabled/unfrozen active managed instance, granted scope and tools-capable model intersect at offering and execution. Execution reloads live authority and checks expected active version/policy revision. Text expresses intent, never authority.

Fixed semantic tools call `HarnessManagementService` and existing lifecycle/resource/validation/evaluation/diff/publication/adoption owners. Source receipts come only from successful content-bearing normal tools in this execution; current owner material uses `conversation:user`. No mandatory Admin source catalog or backdoor fetch exists. Managed knowledge/Skills promote after Core readback/activation/structural checks; Assisted changes, instructions and all tool selection/configuration need exact Chat approval. Tool proposals cannot exceed derived configured authorized eligibility and never approve later concrete actions.

Current Sessions retain immutable Definition pins. Future Sessions use the adopted version. Agent expected/observed assessment remains partial, while Core records actual checks at the candidate revision. Destructive/production/subjective checks remain external. Automatic publication/adoption history uses Agent attribution. Failed adoption may leave an unused immutable publication but preserves the prior active version; fresh changes recover from active state. Safe diagnostics retain server references without exposing private exceptions.

Admin now shows mode/scopes, active version, freeze and collapsed recent change/evidence inspection. Primary prepare/continue/source/eligible/verify/publish controls are gone. Advanced owner lifecycle endpoints remain; `/continue` and the separate model preparation runtime were retired. P11A records authenticated/delegated principal/application/tenant/session authority requirements only.
