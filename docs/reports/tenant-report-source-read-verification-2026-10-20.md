## Implemented behavior

The existing completion coordinator prepares a server-only `ReportSourceRead` ordinary Review when current compound source-read policy requires it. Core freezes the original destination, exact initial and terminal child, terminal revision and bounded report observation/hash. No Artifact metadata or body is included. The model authorization-tool schema cannot originate this operation. Missing raw source reads cannot be replaced with an exceptional grant or report-creation authority.

The terminal child remains terminal and unchanged. Existing approval decisions/signals settle a local read receipt, security revision and audit in one owning transaction; no new Run, source claim, handled accounting or report is created by read consent. Approval permits only the unchanged source under current authority, before separate report-Run creation authorization. A subsequent creation Review or primary-only exceptional creation grant remains independent. Rejection, cancellation, expiry or lost authority skips only still-Pending report intent without disclosure/report creation. Signal settlement is idempotent.

Preparation, decision, receipt, report admission, provider-context use and atomic final save check original-human lineage, current executor, pinned/current capability, configuration and raw child Session/initial/source Run reads. Reuse also requires the exact saved ordinary read request/decision/receipt and current approving-human qualification/independence; no operation grant may substitute. Human saved inspection/cancellation has its independent raw-read qualification. Conversational `CompletionRead` receipts and automatic `ReportSourceRead` receipts have distinct semantic identities and cannot substitute.

Both stores filter pending/refused/unsettled read consent and separately pending report-creation consent before selecting a bounded completion page. Other ready completions remain selectable. Source-read approval visibility independently filters exact source and destination before counts/pages. SQLite migration `20261020140000_TenantReportSourceReadReview` preserves eleven predecessor guards, adds two exact-source/immutable guards, matches the current model and refuses a downgrade that would discard retained consent. The predecessor migration remains frozen.

The shared native inspector shows literal source/task/result, original destination, initial and distinct terminal Run when applicable, checksum and explicit read boundaries. Strict malformed evidence disables approve/reject while retaining cancellation. Protected confirmation and Read authorized distinguish source consent from report creation/delivery. Organization and Chat use the same inspector; no CSS, tokens, UI kit, visual world or assets were added.
