## Current boundary

The shared tenant tool boundary dispatches only trusted claimed Runs to `TenantWorkspaceRuntimeReadService`. The model supplies an exact absolute home/working path and bounded list options; it cannot choose any owner, tenant, principal or grant. The canonical filesystem read port remains the only file owner. Parent Session read, home Agent read, exact workspace read, admitted/current capability, current HomeAccess, original requester/executor status, active Session, claim generation/lease and current operation policy all constrain reads. The same checks repeat after I/O. Missing raw authority and Review-required policy return no file data; neither creates consent or falls back to a legacy adapter.

UTF-8 body output is bounded and untrusted. Binary text and missing paths return safe errors without physical roots. Listings fit whole entries with a continuation at the last emitted path. Empty reads create no directories. These are current mutable observations, not stable file IDs, snapshots, file CAS or mutation rights. Core-owned checkpoint scope markers cause current authorization/policy/capability/HomeAccess checks before retained output is reused through the existing execution and continuation owners. They do not reread historical body bytes or authorize another path.

Canonical owners: [ports](../04-backend-interfaces.md#tenant-model-workspace-observations), [testing](../16-testing-strategy.md#tenant-model-workspace-reads).
