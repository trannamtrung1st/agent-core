# P9.10 identity state consolidation verification

Status: implementation candidate; final local and exact-commit hosted acceptance is being completed. P9.8/P9.9 remain frozen on `0a3330db`; P10/P11 remain unopened. This report concerns the accepted `agent-core-p9.10-identity-state-consolidation-proposal.md` follow-on.

## Delivered behavior

Two to eight unique same-owner/scope/kind Active memories can become one canonical Active memory with exact immediate parent lineage. Both storage adapters atomically supersede sources, enforce active subject uniqueness, preserve source content and relieve active capacity. Experience uses its separate store and existing content contract: Consolidation observations carry parent IDs and Superseded sources remain inspectable. Neither operation creates an Experience-to-Memory promotion.

A durable, default-off Allow agent consolidation setting uses owner CAS configuration and audit. Safe Thought consolidation of inferred IdentityUser memory and eligible Experience reuses existing durable WorkItems; protected user-explicit/User Memory uses exact approvals. Live UserTurn maintenance conservatively requests exact approval. Forgotten learned memory becomes a content-free tombstone; source Sessions, Experience, files and other retained data are independently owned. Current policy, inactive/compatibility ownership, disabled permission, source changes and destructive visibility are rechecked. Exact local effects are replay-safe with deterministic result IDs, not a generic external exactly-once promise.

Admin displays permission/loading/stale-reload, Consolidated/Superseded state, immediate parents and origin. Historical Memory inspection includes retained source content and tombstones. Semantic approval shows every source and the full bounded replacement rather than clipping its qualifiers. Existing Ant Design v6 panels, details, tables, typography, confirmation and Runs remain shared. IDs/content wrap; tables scroll locally at narrow widths.
